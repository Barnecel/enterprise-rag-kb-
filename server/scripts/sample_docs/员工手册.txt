员工手册 v2.0
=============

第一章 公司简介
--------------
我们公司成立于2010年，专注于企业服务领域十余年。公司总部位于北京，在全国设有多个分支机构。

公司使命：用科技提升企业效率
核心价值观：创新、协作、诚信、务实

第二章 规章制度
--------------
1. 上班时间：周一至周五 9:00-18:00
2. 午休时间：12:00-13:00
3. 迟到超过30分钟视为旷工
4. 请假需提前一天申请

第三章 考勤管理
--------------
1. 员工上下班需通过企业微信打卡，每日两次（上班、下班各一次）
2. 忘记打卡当月可补卡3次，超过3次每次扣款50元
3. 迟到或早退30分钟以内，每次扣款100元；超过30分钟视为旷工半天
4. 旷工一天扣除当日工资的300%，当月旷工累计3天及以上视为严重违纪，公司有权解除劳动合同
5. 加班需提前在OA系统提交申请并经部门主管批准
6. 工作日加班按1.5倍计算加班费（或1:1.5调休）；周末加班按2倍计算；法定节假日加班按3倍计算
7. 调休假自生成之日起3个月内有效，过期自动清零
8. 出差在外无法打卡的，返回后凭审批单由行政补录考勤

第四章 假期制度
--------------
一、带薪年休假
1. 员工累计工作满1年不满10年的，年休假5天；满10年不满20年的，年休假10天；满20年的，年休假15天
2. 工作年限以累计社会工龄计算，入职时提供前单位离职证明核定
3. 入职不满一年的新员工，按剩余日历天数比例折算年假
4. 年休假原则上当年使用，未休完的可顺延至次年3月31日前补休
5. 申请年假需提前5个工作日在OA系统提交，一次请假原则上不超过10天
6. 员工离职时年假按当年已工作时间比例折算，折算后已休超部分不再扣回

二、病假
1. 病假需提供二级及以上医院开具的诊断证明和病假条
2. 每月享有1天全薪病假，无需扣减工资
3. 超出全薪额度的病假，病假期间工资按当地最低工资标准的80%发放
4. 连续病假3天及以上的，需向人力资源部备案并保留就医票据

三、事假
1. 事假为无薪假，按日扣除工资
2. 全年累计事假不得超过15天，超过的超出天数按旷工处理
3. 事假需提前1个工作日申请，紧急情况可事后24小时内补办手续

四、婚假
1. 员工登记结婚可享受婚假10天（含国家规定3天及地方奖励假），需在领证后12个月内一次性休完
2. 申请时需提交结婚证复印件

五、产假与陪产假
1. 女员工产假共158天（含国家规定98天及地方奖励假60天）
2. 男员工享有陪产假15天，需在子女出生后一年内使用
3. 产假期间按规定发放生育津贴，差额部分由公司补足

六、丧假
1. 直系亲属（父母、配偶、子女）去世，丧假5天；祖父母、外祖父母去世，丧假3天
2. 需异地奔丧的，另给路程假2天

七、请假流程
1. 所有假期统一通过OA系统申请，经直属主管审批后生效
2. 请假3天（含）以内提前1个工作日申请；3天以上提前3个工作日申请；年假一律提前5个工作日申请
3. 未经批准擅自离岗的按旷工处理

第五章 薪酬福利
--------------
1. 工资发放日期：每月15日（遇节假日提前至最近工作日）
2. 五险一金按国家规定执行，缴费基数为上年度月平均工资
3. 年终奖根据公司业绩和个人绩效发放，于次年3月31日前发放完毕
4. 节日福利按传统节假日发放，春节、中秋发放节日礼品卡
5. 公司为全体员工购买补充商业医疗保险，门急诊、住院费用社保报销后自付部分可二次报销
6. 每年组织一次免费体检，体检时间为每年9-10月
7. 餐补标准为每月600元，交通补贴每月300元，随工资发放

第六章 行为规范
--------------
1. 上班时间穿着得体，商务场合着正装
2. 会议室使用需提前预约，使用后恢复原状
3. 公司资源不得私用，办公设备不得带离公司
4. 保守公司商业秘密，离职后两年内不得从事同业竞争业务
5. 同事之间互相尊重，禁止任何形式的职场骚扰

如有疑问请联系人力资源部（hr@company.com，分机8001）。
