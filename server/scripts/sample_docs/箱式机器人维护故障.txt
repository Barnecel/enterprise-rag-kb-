箱式机器人维护故障技术文档
================================

1. 系统概述
----------
箱式机器人（Cartesian Gantry Robot / Box-type Robot）是一种以直线驱动为主的工业机器人，
工作形式为X/Y/Z三轴直线运动，常用于3D打印、喷涂、装配、搬运等工业任务。
其核心结构包括：框架支柱、直线电机/滚珠丝杠、电动缸、滑块、传感器、控制柜。
故障率主要集中在机械传动、电气控制和环境干扰三个方面。

2. 常见故障与诊断
----------------

2.1  电机无转/转速不稳
可能原因：
  - 电源电压异常（低电压、电压波动）
  - 相序错误或缺相
  - 编码器信号丢失/脏污
  - 电机绕组短路或开路
  - 驱动器参数不匹配

诊断步骤：
  1. 用多用表测量驱动器输入电压，对比额定电压（通常 220V/380V ±10%）
  2. 检查三相电源是否缺相（用钳形电流表检测三相电流是否均衡）
  3. 断电检查编码器连接器，清理编码器光盘/磁感应头
  4. 电机卡盘测量绕组电阻，对照电机铭牌值检查是否开路/短路
  4. 更换驱动器参数组（电流环、速度环PID参数），或更换电机

2.2  直线电机/丝杠异响/过热
可能原因：
  - 润滑不足或润滑脂老化
  - 传感器（光电/磁感应）检测到的位置超程
  - 传动带/丝杠松动，产生反向间隙
  - 超负载运行， duty cycle 超限

诊断步骤：
  1. 目视检查丝杠/带是否有油污、粉尘、磨损痕迹
  2. 听异响性质：金属刮擦声→导轨干涩；金属撞击声→碰撞超程
  3. 用振动仪测量振动频谱，主频偏离正常值±10%则判定机械松动
  4. 检查负载是否超过额定值，计算 duty cycle：(运行时间/(运行时间+静止时间))×100%
  5. 若润滑干润，按说明书加注润滑脂；若超负载则减小单次搬运重量或提高循环频率

2.3  传感器误报/信号丢失
可能原因：
  - 环境磁场干扰、电磁干扰 (EMI)
  - 光电传感器玻璃/塑料窗口灰尘/油污
  - 磁性传感器靶铁间距不匹配
  - 信号线屏蔽层接地不良

诊断步骤：
  1. 逐个检查每路传感器信号电压（空载时应在 3.3V~5V 或 0~10V 范围内）
  2. 使用示波器观察信号波形是否有噪峰
  3. 逐屏蔽法排除干源：断开一路信号，观察故障是否移转
  4. 若为EMI，在信号线两端并联RC滤波电路（R=1kΩ, C=0.1μF），或加装铁氧体磁环
  4. 清洁传感器窗口，重新对准/间距调整

2.4  控制柜过热/风扇报警
可能原因：
  - 环境温度超过设计上限（>40℃）
  - 灰尘堵塞风扇散热片
  - 风扇电路板老化损坏
  - 过载保护触发，实际负载大于额定负载的 110%

诊断步骤：
  1. 测量柜内温度，若>45℃则检查外部通风是否畅通，增设排风扇
  2. 用压缩空气吹净风扇和散热片，去除灰尘
  3. 用万表测量风扇电压和电流，判断是否正常
  4. 重置过载保护器，空载运行24h监控温升，若仍超限则更换风扣或加装额外散热

3. 预防性维护清单
------------------------
| 保养项目           | 周期     | 要点                                     |
|------------------|----------|----------------------------------------|
| 导轨润滑         | 每月 1 次| 涂抹专用导轨油，厚度均匀              |
| 电机/编码器检查  | 每季度 1 次| 清理灰尘，检查连接器触点是否腐蚀       |
| 传感器校准       | 每半年 1 次| 用标准位移块校准零点/满量程             |
| 丝杠/同步带张力  | 每半年 1 次| 检查松弛度，调整至规定扭矩重新锁紧      |
| 散热风扇清理     | 每季度 1 次| 压缩空气吹净，核对风向是否符合规范      |
| 整机外观检查     | 每月 1 次| 核对螺丝是否松动，外观是否有碰撞痕迹    |

4. 故障码速查表
------------------------
| 现象代码 | 部件       | 可能原因                  | 处置方案                        |
|----------|------------|--------------------------|--------------------------------|
| E01      | 电机未转   | 电源缺相                 | 检查电源线、重接缺相            |
| E02        | 电机过热   | 超负载、散热不良         | 清理风扇、减小负载、增设散热      |
| E03        | 位置超程   | 传感器未校准、程序逻辑错 | 重新原点校准、修改程序            |
| E04        | 通信中断   | 总线线路松动、地位不良   | 重新插拔连接器、加装接地线        |
| E05        | 电位器无效 | 传感器脏污、信号衰减     | 清洁传感器、更换信号线            |
| E06        | 急停失效   | 继电器粘连、电路断路     | 更换急停继电器、检修电路          |

5. 紧急处理流程
----------------
1. 立即停机：按急停按钮，切断主电源
2. 记录故障现场：拍照/录像，记录故障码、环境温度、负载情况
3. 报告主管：通过OA系统提交故障单，注明故障代码和初步判断
4. 维护处理：按上表对照故障码进行排查，更换部件或重新调参
5. 复位验证：清除故障码，空载无负载运行 1 循环确认恢复正常
6. 归档分析：将故障记录入库，分析规律，优化预防性维护计划
