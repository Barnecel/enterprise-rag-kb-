汽车故障码技术文档 (OBD-II 体系)
================================

1. 编码体系概述
----------------
OBD-II (On-Board Diagnostics II) 是美国联邦法律规定的车载诊断系统标准，
适用于1996年后销售的几乎所有乘用车。故障码由5位字符组成，第一位
字母表示系统类型，后三位数字表示具体故障。

代码分类：
- P (Powertrain): 发动机与变速箱相关 (最常见)
- B (Body): 车身系统 (气囊、门锁等)
- C (Chassis): 底盘与底盘控制
- U (Network): 网络通信故障

2. 常见故障码详解
------------------

2.1  P0300  - 随机/多缸 misfire detected
可能原因：
  - 火花塞老化/积 carbon
  - 燃油喷射器堵塞或喷射不均
  - 真空泄漏
  - 点火线圈损坏
  - 发动机电脑 (ECM) 故障

检修步骤：
  1. 使用扫描仪读取所有存储的码，判断是单缸 misfire 还是随机
  2. 检查火花塞状况，根据车辆行驶里程更换老化火花塞
  3. 检查燃油喷射系统压力，清洗或更换燃油滤芯
  4. 检查真空管路是否有裂纹或松动
  5. 测试点火线圈输出，有故障则更换
  6. 若以上无效，检查发动机电脑参数或更新ECM软件

清码方法：扫描仪清码或断开电池负极 10 分钟后重新接通（需备注：清码后需行驶一定里程重新检测）。

2.2  P0171  - Fuel trim too lean (Bank 1)
可能原因：
  - 进气系统真空泄漏
  - 燃油压力不足 (燃油泵弱、燃油滤堵)
  - 氧传感器 (O2) 故障或脏污
  - 空气质量流量计 (MAF) 故障

检修步骤：
  1. 听是否有进气歧管真空泄漏声（喷嘴喷油声或用烟雾机检测）
  2. 检查燃油压力表读数，对比规格值；燃油泵电压/电流异常则更换燃油泵
  3. 清洗 MAF 传感器（用专用清洁剂，勿用螺丝刹刮擦线圈）
  4. 逐个检测氧传感器电压波形，懂电路则用示波器；无专用工具则先更换一侧氧传感器观察效果
  5. 清码后路测，确认故障是否复现

2.3  P0420  - Catalyst system efficiency below threshold (Bank 1)
可能原因：
  - 三元催化 converter 效率下降 (老化、里程超过 10 万公里)
  - 进排气漏气
  - 燃油质量差 导致 催化剂毒化
  - 氧传感器（上下游）失真

检修步骤：
  1. 用红外测温仪测量排气歧管上下游氧传感器前温度，若差温极小基本可确认催化剂效率低
  2. 检查排气系统是否有泄漏点（听声辨位或涂石膏水）
  3. 若催化剂里程超过 8 万公里，建议直接更换高质量催化剂
  4. 同步更换上下游氧传感器（推荐原厂或同等级别）

2.4  C1201  - ABS 电路故障 (通用厂商码)
可能原因：
  - ABS 传感器线路断路或短路
  - ABS 传感器积碎/磨损
  - ABS 模块内部故障
  - 雨雪天导致传感器被异物遮挡

检修步骤：
  1. 目视检查 ABS 传感器线路是否有破损、磨损
  2. 使用万欧表测量传感器阻值，对比规格（通常 1-2 kΩ 左右）
  3. 清理传感器表面的铁屑/油泥
  4. 实路测试：低速急刹车，观察 ABS 系统是否介入；若无反应，检查或更换 ABS 模块

2.5  U0101  - Lost communication with TCM
可能原因：
  - 变速箱控制模块 (TCM) 供电不良
  - 总线 (CAN/LINE) 线路损耗/断路
  - TCM 固件过旧或损坏
  - 总线调制器故障

检修步骤：
  1. 检查 TCM 连接器触点是否腐蚀、松动
  2. 使用扫描仪查看其他模块（发动机、仪表）是否正常通信，排除总线整体故障
  3. 测量 TCM 供电电压（应为 12V ±0.5V），若无则检查保险丝/线路
  4. 如确认总线完好但仍报码，考虑刷新或更换 TCM 固件

4. 实战小技巧
----------------
- 入手一把好扫描仪（支持 CAN/OEE 模式），比单纯靠代码查表靠谱得多。
- 同一辆车反复出现同一码，先清码后路测，看码是否复现——很多是间歇性故障（进水、振动松动）。
- 码子只能定位大方向，具体维修仍需结合车辆症状（怠速抖动、异响、油耗突增等）和多媒体诊断数据。
- 维修后一定要行驶综合工况（城乡道路 + 高速）至少 50 公里，让车电脑重新完成自学习周期，避免假性故障。
